# Airgapp console demo

The real Airgapp console running entirely in your browser, with pretend data:
the console's Go server compiled to WebAssembly, so nothing you do here talks to a box or a car.
It resets every time you reload.

Live at https://demo.airgapp.net. Built from [airgapp-rpi](https://github.com/ivan-prodanov/airgapp-rpi)'s `cmd/preview`.
